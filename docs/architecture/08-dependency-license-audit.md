# Dentiva Pro — Dependency, Licence and Cost Audit (Phase 0)

Rules applied:
1. Every production dependency must be usable in a commercial, redistributable Windows application.
2. No paid API, paid SDK, paid cloud database, paid AI service, paid analytics, mandatory cloud storage or
   recurring third-party subscription may be required for normal operation.
3. Redistribution obligations (notices, source availability, relinking) are recorded and satisfied.

Versions below were resolved during Phase 0 against PyPI for `win_amd64` / CPython 3.12 (verified
downloadable). Exact pinned versions land in `requirements.lock` in Phase 1.

## 3. Paid / cloud dependency audit

| Candidate service | Needed? | Decision |
|---|---|---|
| Cloud database (Firebase/Supabase/Azure SQL) | No | Local SQLite is the product's architecture |
| Online licence server | No | Fixed offline activation |
| SMS/email gateways | No | Notifications are in-app; phone/WhatsApp actions use the OS default handler |
| Payment gateways | No | Payments are recorded, not processed |
| AI/LLM APIs | No | No generative feature in this product |
| Analytics/crash reporting SaaS | No | Local structured logs + diagnostics export |
| Cloud backup storage | No | Local folder / USB / network share chosen by the clinic |
| Paid PDF SDK | No | Qt `QPdfWriter` (LGPL) generates PDFs offline |
| Paid UI component suites | No | Design system is built in-repo |
| Code signing certificate | Not required to build, **recommended for release** | If a certificate is provided, CI signs; otherwise the release is documented as unsigned |

**Conclusion:** the product has zero recurring third-party cost. Its only external requirement is a
Windows PC.

## 4. Licensing obligations checklist (implemented in Phase 1 and audited in Phase 10)

- [ ] `THIRD_PARTY_NOTICES.md` at repo root and `assets/notices/` in the installer with full licence texts
      (LGPL-3.0, Qt, PSF, MIT, BSD, Apache-2.0, ISC, OFL-1.1, zlib).
- [ ] About → "Open-source notices" screen renders these notices in-app.
- [ ] Qt/PySide6 dynamically linked; application does not statically link LGPL components; DLLs remain
      replaceable in the onedir bundle (documented in the README: "To replace the Qt libraries, replace
      the DLLs in the `PySide6\Qt\bin` folder").
- [ ] No modification of LGPL components (patches, if ever needed, would be published).
- [ ] OFL fonts bundled unmodified with their licence files; not sold standalone.
- [ ] `tools/qa/check_licenses.py` validates that every dependency in `requirements.lock` has a declared
      licence in this document and that no GPL/AGPL (non-excepted) package entered the production set;
      a CI failure otherwise.
- [ ] SBOM (`dist/sbom.json`, CycloneDX-style, generated from the lock file) attached to the release.

## 5. Third-party code re-use

The application uses libraries only as dependencies; no third-party source code is copied into the
repository. Where algorithms follow published standards (Argon2id, PBKDF2, HKDF, AES-GCM, FDI tooth
numbering), the standards are referenced in docstrings, not copied implementations.
